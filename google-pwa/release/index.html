VARKA Release Automation

Deployment tooling for the owner of the VARKA inventory application. The Desktop OAuth client, VARKA Release CLI, connects an owner-run setup command and a GitHub Actions release to an existing Google Apps Script project. Changes pushed or merged to the protected main branch release automatically after the Node and browser checks pass.

What it does

A release verifies the selected GitHub commit and current main branch, updates four managed Apps Script files, updates the existing web deployment, and publishes the phone interface on GitHub Pages. Original project files, deployment settings, Script Properties, and the existing deployment URL are preserved. The release supplies that URL to the app; normal staff sign-in needs only email and an individual access code.

Google authorization

The helper requests only script.projects and script.deployments to read and update script source and deployments. These permissions can apply to scripts accessible to the authorizing account; the configured project and deployment IDs select the release target. The helper does not request direct Google Sheets, Drive, or Gmail access.

Authorization is for the project owner. Staff sign in to the inventory application using their existing VARKA access credentials. A release does not submit inventory, run database installers or scheduled triggers, or send a Telegram test.
