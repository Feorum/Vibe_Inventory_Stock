Terms of use

VARKA Release Automation and its Desktop OAuth client, VARKA Release CLI, are deployment tools for authorized operators of the VARKA project. Use them only with Google and GitHub resources you own or have permission to manage.

Before a release

Follow the release guide. Review the selected commit, verify the configured project and existing deployment IDs, confirm the intended copied workbook, and keep the GitHub environment restricted to the approved branch. Pause manual script edits during deployment.

Operational limits

A release can change Apps Script project HEAD, which also affects editor runs and installable triggers. Updating Apps Script and publishing GitHub Pages are separate operations. If a step fails or times out, inspect the current deployment before retrying. A successful release is not a test of inventory counting, notification delivery, or a physical phone.

The workflow does not configure staff access, change Script Properties, migrate the workbook, run installers or scheduled triggers, or submit stock counts as a smoke test. Operators remain responsible for reviewing the target and completing acceptance checks on the intended test copy.

Accounts and access

Google and GitHub services remain subject to their respective terms and account policies. Keep the downloaded client JSON and release credentials private. The privacy page explains the authorization flow, storage, and revocation options.
